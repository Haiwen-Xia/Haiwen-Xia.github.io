# Haiwen Xia's website

Source for [haiwen-xia.github.io](https://haiwen-xia.github.io/), built with Jekyll and the AcademicPages theme.

## Local preview

With Ruby and Bundler installed, run:

```sh
bundle install
bundle exec jekyll serve --config _config.yml,_config.dev.yml
```

The site will be available at `http://localhost:4000/`. The development configuration disables the production visitor counter.
